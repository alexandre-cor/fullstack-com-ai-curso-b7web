#Solicitação de Ajustes na Landing Page

Rigorosamente siga estas diretrizes de CSS baseadas nos meus ajustes:
1. Arquitetura Mobile-First: Escreva primeiro o CSS para telas de celular.
2. Breakpoint de Desktop: Use a Media Query @media (min-width: 900px) para aplicar as regras de telas grandes.
3. No layout de Desktop (telas >= 900px):
   - Aplique "align-items: center;" na classe `.hero-right`.
   - Aplique "align-items: flex-end;" na classe `.hero-left`.
